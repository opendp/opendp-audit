# `rust/src/traits/arithmetic/mod.rs`

## Scope and assumptions

- **Scope:** The `InfSqrt for f64` implementation generated by `impl_float_inf_uni!` and its use in the non-deprecated floating-point Gaussian `get_rounding_distance<T,2>` stability allowance. Other transcendental functions and arithmetic traits are out of scope.
- **Invariant:** For finite nonnegative `y`, successful `y.inf_sqrt()` must yield `z` such that the exact real `z^2 >= y`. Together with upward `usize->f64` casting, this guarantees `z >= sqrt(n)` for a size `n` used in the L2 allowance.
- **Assumptions:** Directed `FBig<Up>` sqrt, `Self::inf_cast`, and backend precision semantics are correct. Only the upstream source and existing Rust tests were read; no Rust execution occurred. Reviewed revision `ef1a238634d6196b01a1a1e77d3d5ad2340e3094`.

## Analysis

### Implementation path

`impl_float_inf_uni!(f64, f32; InfSqrt, inf_sqrt, neg_inf_sqrt, sqrt)` generates the upward square-root operation. It first checks its input, passes it into `FBig::<Up>::inf_cast`, uses a precision of `f64::MANTISSA_DIGITS`, computes `lhs.sqrt()` under `FBig<Up>`, converts the result back with `Self::inf_cast`, and rejects invalid/nonfinite outputs. This is consistent with an upward bound, conditional on the actual dashu backend and rounding mode.

Existing upstream `test_inf_sqrt` asserts outward bounds for `sqrt(6)`, `sqrt(0.1)`, and `sqrt(24)`; these tests were inspected, **not run**. An independent Python reference test computed a candidate sqrt from a binary64 value, adjusted upward when its exact square was below the value, and verified the bound using exact `Fraction` arithmetic for **9,484** 64-bit size inputs. None failed. Python reference results are not a native Rust backend test.

The cross-file path is `f64::inf_cast(size)?.inf_sqrt()?` in `get_rounding_distance`, with `RBig::try_from` converting the *resulting float exactly* to a rational. Thus a directed upper bound at each stage suffices to avoid a privacy-optimistic L2 multiplier.

**Result:** No counterexample within the reference-model test and reviewed source contracts; the implementation property is **Partial** until actual `FBig` semantics and compiled Rust behavior are verified.
